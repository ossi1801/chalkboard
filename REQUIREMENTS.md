# APP_NAME chalkboard

A blackboard paint like drawing app 

the focus is to create something that has the features of ;
https://invent.kde.org/graphics/drawy
and
https://excalidraw.com/



#Technological

The entirity of the project should be done with Fabric.js
https://www.fabricjs.com/
This includes brushes etc.

Also we use static js libraries. Nodejs is banned for the actual dev purposes.



# Deployment
app will be deployed in 2 types.

1. Github pages online version (browser usage), most important.

2. Electron app that is portable to Windows 11, Linux, MacOS
